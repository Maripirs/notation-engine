notation-engine, Phase 0 spike

Own model, own layout, own canvas renderer, Bravura for glyph shapes. Click a notehead or rest to select it, then transpose it with the buttons or ↑ / ↓. Each edit re-lays-out and repaints only the measure that changed; the timings below compare that against repainting the whole system. The score is capped at a fixed width, so it casts measures off onto a new system (a new staff line) rather than shrinking to fit; each system repeats the clef and key signature, as real engraving does. Zoom in/out (M4 Slice 3) re-lays-out the whole score at a different staffSpacePx, the single knob that scales the whole render: whatever note is currently selected or under the playback cursor stays correctly highlighted through the rescale, with no extra call telling it to. The score sits in a height-capped scrolling box, so it does not all fit on screen at once; during playback (below) the box auto-scrolls to keep the playback cursor's current measure in view as it moves into later systems (M4 Slice 4), using regionForNote for the target rectangle and a plain scrollTo here in the demo for the actual scroll. Every transpose is recorded in an EditHistory, so Undo / Redo (or Cmd/Ctrl+Z, Shift+Cmd/Ctrl+Z) step back and forth through it with a whole-score re-layout, and Save downloads the current score as MusicXML and clears the unsaved-changes flag.
