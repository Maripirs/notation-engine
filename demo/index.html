notation-engine, Phase 0 spike

Own model, own layout, own canvas renderer, Bravura for glyph shapes. Click a notehead or rest to select it, then transpose it with the buttons or ↑ / ↓. Each edit re-lays-out and repaints only the measure that changed; the timings below compare that against repainting the whole system. The score is capped at a fixed width, so it casts measures off onto a new system (a new staff line) rather than shrinking to fit; each system repeats the clef and key signature, as real engraving does. Zoom in/out (M4 Slice 3) re-lays-out the whole score at a different staffSpacePx, the single knob that scales the whole render: whatever note is currently selected or under the playback cursor stays correctly highlighted through the rescale, with no extra call telling it to. The score sits in a height-capped scrolling box, so it does not all fit on screen at once; during playback (below) the box auto-scrolls to keep the playback cursor's current measure in view as it moves into later systems (M4 Slice 4), using regionForNote for the target rectangle and a plain scrollTo here in the demo for the actual scroll. Every transpose is recorded in an EditHistory, so Undo / Redo (or Cmd/Ctrl+Z, Shift+Cmd/Ctrl+Z) step back and forth through it with a whole-score re-layout, and Save downloads the current score as MusicXML and clears the unsaved-changes flag. Show seam markers (M5 Slice 6) overlays red strips at a few measure boundaries, one of them at a system break, the way an OMR host would mark where stitched scan fragments meet; they are render-only, and survive a transpose's scoped redraw of a neighbouring measure. The score ends with M6 Slice 2's chord showcase (triads, seconds on both sides of the stem, stacked accidentals, divisi thirds, beamed and tied chords, two chordal voices); Open MusicXML replaces it with any MusicXML file, e.g. an SFCC fixture from src/test/fixtures/sfcc/ such as Les Djinns. Every chord head is its own note: click one and transpose it alone.

Correction shortcuts (M6 Slice 7), on the selected note

For fixing rough OMR output, e.g. Les Djinns opened from src/test/fixtures/sfcc/. Every one is a single undoable step (Cmd/Ctrl+Z), and repaints only the measures it touched unless the measure's width changed. Nothing ever shifts into the next measure: a shorter value is padded with rests, a longer one takes time from the rests right after it (and is refused if a note is in the way).

  • Delete / Backspace: note to rest of the same length (on a chord head: remove that head)
  • R: rest to note on the staff's middle line, or note to rest
  • 1–7: whole, half, quarter, eighth, 16th, 32nd, 64th
  • .: toggle a dot
  • Shift+↑ / Shift+↓: add a chord head a third above / below
  • T: tie to the same pitch in the next note, or untie
  • ↑ / ↓: transpose a semitone
